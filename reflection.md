# Reflection

## Challenges Faced During the Project
One challenge I faced was connecting HTML elements with JavaScript correctly. I also had issues with the status dropdown, filtering tasks, and updating the correct task. Another challenge was using `localStorage` so that tasks and their updated status would stay saved after refreshing the page. I also had to make sure the deadline correctly changed the status to "Overdue."

## How I Approached Solving Those Challenges
I checked my HTML IDs and JavaScript carefully when I received errors. I separated the code into functions like `displayTasks()`, `filterTasks()`, `checkOverdueTasks()`, and `loadTasks()` to make the code easier to understand. I used the browser console to find errors and tested each feature step by step. I also used `localStorage` to save the task data and status changes.

## What I Would Improve With More Time
With more time, I would add edit and delete buttons for tasks. I would also improve the category filter to avoid duplicate categories and make the application look more user-friendly. I would like to add sorting by deadline as another useful feature.
